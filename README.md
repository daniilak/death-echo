# Death Echo

Fabric-мод для Minecraft 1.21.1. Каждая смерть оставляет призрака на месте гибели. Он бесконечно повторяет последние 5 секунд: бег, падение, присед и предмет в руке.

Призрак держит твои вещи. Пока он жив, дроп с земли забирается к нему. Пока его не ударить, он только повторяет смерть и задевает, если влезть в запись. Удар срывает его с петли: он дерётся, пока кто-то не погибнет или ты не отойдёшь. Бьёт он только своего хозяина, и забрать лут может только тот, кто умер. Пустой призрак тает через полторы минуты. С вещами остаётся, пока его не убьёшь. Одновременно живыми остаются четыре последних пустых повтора.

Призраки рядом замечают друг друга и перебрасываются репликами. На 12-й смерти в мире само появляется кладбище: площадка, таблички и до восьми прошлых «я». Кто-то тобой гордится, кто-то считает идиотом. Сколько смертей до него осталось, чат не говорит. Если встать на песок душ в центре, они замолкают и нападают. Отойдёшь — возвращаются на места. Убить их можно, лута на них нет. Площадка ставится рядом с местом смерти и заменяет блоки на участке 15×15, кроме бедрока, порталов и сундуков.

Кадр пишется каждые 0.25 секунды: позиция, поворот, присед, спринт, взмах руки и предмет. На смерти из этих кадров собирается актёр.

Правило `keepInventory` и креатив призрак не обкрадывают: вещи остаются у тебя, запись всё равно проигрывается.

## Требования

- Minecraft 1.21.1
- Fabric Loader 0.16 или новее
- Fabric API
- Java 21 для сборки из исходников

## Установка

Соберите мод и положите `build/libs/death-echo-0.1.0.jar` в папку `mods`.

Для Prism Launcher нужен инстанс Minecraft 1.21.1 с Fabric API. Положите JAR в папку `mods` и перезапустите игру.

## Команды

- `/ghosts` — сколько смертей. Координаты кладбища команда пишет только после того, как оно уже есть.
- `/ghosts graveyard` — собрать кладбище сразу. Нужны права оператора. Повторно оно не строится.

## Сборка

Нужен JDK 21.

```bat
gradlew.bat build
```

На Linux и macOS:

```sh
./gradlew build
```

Готовый файл: `build/libs/death-echo-0.1.0.jar`.
