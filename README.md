# Death Echo

Fabric-мод для Minecraft 1.21.1. Каждая смерть оставляет призрака на месте гибели. Он бесконечно повторяет последние 5 секунд: бег, падение, присед и предмет в руке.

Призрак держит твои вещи. Пока он жив, дроп с земли забирается к нему. Чтобы вернуть инвентарь, призрака нужно убить. Бьёт он только своего хозяина, и забрать лут может только тот, кто умер.

Призраки рядом замечают друг друга и перебрасываются репликами. На 50-й смерти в мире появляется кладбище: площадка, таблички и до восьми прошлых «я». Кто-то тобой гордится, кто-то считает идиотом. Площадка ставится рядом с местом смерти и заменяет блоки на участке 15×15, кроме бедрока, порталов и сундуков.

Кадр пишется каждые 0.25 секунды: позиция, поворот, присед, спринт, взмах руки и предмет. На смерти из этих кадров собирается актёр.

Правило `keepInventory` и креатив призрак не обкрадывают: вещи остаются у тебя, запись всё равно проигрывается.

## Требования

- Minecraft 1.21.1
- Fabric Loader 0.16 или новее
- Fabric API
- Java 21 для сборки из исходников

## Установка

Соберите мод и положите `build/libs/death-echo-0.1.0.jar` в папку `mods`.

Для Prism Launcher нужен инстанс Minecraft 1.21.1 с Fabric API. Положите JAR в папку `mods` и перезапустите игру.

## Команды

- `/ghosts` — сколько смертей и где кладбище.
- `/ghosts graveyard` — собрать кладбище сразу. Нужны права оператора. Повторно оно не строится.

## Сборка

Нужен JDK 21.

```bat
gradlew.bat build
```

На Linux и macOS:

```sh
./gradlew build
```

Готовый файл: `build/libs/death-echo-0.1.0.jar`.
