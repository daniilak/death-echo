# Changelog

## 0.1.0

- каждая смерть оставляет призрака, который повторяет последние 5 секунд;
- вещи умершего забирает призрак, вернуть их можно только боем с ним;
- рядом призраки замечают друг друга;
- на 12-й смерти в мире появляется кладбище, без отсчёта в чате;
- удар хозяина срывает призрака с записи, пустые повторы тают;
- песок душ в центре кладбища будит прошлых тебя.
